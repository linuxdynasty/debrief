How to read this scorecard
  • Sessions Used: Chats that loaded this skill in transcripts (higher = more impact if you improve it).
  • Hook Loads / Nudged %: Loads caught by live hooks, and how often a hook had to remind the agent to load it (lower Nudged % is better; high % means the skill description is not triggering naturally).
  • Total Tokens: This skill's equal share of all tokens spent in sessions that loaded it.
  • Skill Overhead (tok): Estimated extra tokens spent keeping the SKILL.md text in context across turns (high overhead = good candidate to trim or split into references/).
  • Reply Gap / Session Len: Typical wait between your replies (seconds) / typical total session duration (minutes).
  • Errors (Avg / Session): Total tool errors attributed to sessions using this skill, and average errors per session (high avg/sess = check Where Things Go Wrong or file a papercut).
  • Issues (Open / Fixed): Open vs fixed papercut issues tied to this skill (populated when --papercuts is passed).
  • A/B Win Rate (±Noise): How often the skill beat a stripped no-skill run in blind replay evals, plus the A/A judge noise band (win rate clearly above noise = proven lift; inside noise = inconclusive or noisy judge).
